# Internal exports: the typeinfo of an exception type the library throws.
#
# Each line is a symbol that names a LibreSCRS entity the installed headers do
# not declare (or one in an Internal/detail scope) and is exported anyway,
# because a throw of its type leaves the shared object and a catch elsewhere
# matches only the one exported typeinfo. Read by ci/scripts/abi-snapshot.sh;
# these symbols are not recorded in 5.x-baseline.txt, because they are no
# contract with any consumer.
#
# Format: <library section> TAB <demangled symbol, exactly as abi-snapshot.sh
# prints it> TAB thrown: <why>. Only the typeinfo, typeinfo name and vtable of
# an exception type qualify; the gate fails an entry when the library contains
# no throw of the type. Nothing is listed for an importer: no shipped image (a
# core library, a card plugin, the installed test archive) may import an
# internal symbol, and the gate refuses an "imported:" entry.
#
# This list only shrinks. The gate fails on an internal export that is not
# here, on an entry that no longer names an internal export, and in CI on any
# entry the list at the merge base does not hold.
