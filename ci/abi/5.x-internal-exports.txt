# Each line is a symbol that names a LibreSCRS entity the installed headers do
# not declare (or one in an Internal/detail scope), and that cannot be hidden
# yet. Read by ci/scripts/abi-snapshot.sh; these symbols are not recorded in
# 5.x-baseline.txt, because they are no contract with any consumer.
#
# Format: <library section> TAB <demangled symbol, exactly as abi-snapshot.sh
# prints it> TAB <reason>. The reason is one of
#   imported: <who>  -- a shipped image (a core library, a card plugin, the
#                       installed test archive) imports it; the gate fails the
#                       entry when none does;
#   thrown: <why>    -- the typeinfo of an exception type that leaves its
#                       library, which a catch in another image needs exported.
# Test executables are not shipped and are never a reason.
#
# This list only shrinks. The gate fails on a symbol that is not here, on an
# entry that no longer names an imported internal export, and in CI on any
# entry the list at the merge base does not hold.
